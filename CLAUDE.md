# ketai

## Language rules

- **Documentation** (`README`, `CONTRIBUTING`, `docs/`, `examples/` guides) is
  bilingual: **English is the primary version** and every document has a
  **Spanish copy** kept in sync in the same change. Follow the
  `bilingual-docs` skill (`.claude/skills/bilingual-docs/SKILL.md`) for paths,
  rules and the checklist.
- **Code comments** are written in Spanish.
- Everything in Spanish (code comments and the Spanish documentation) uses
  ASCII-only characters: no accents, tildes, or special characters. Write
  `cancion`, `reproduccion`, `ano`, `senal` (not `canción`, `reproducción`,
  `año`, `señal`).
- Do not use inverted punctuation (`¿`, `¡`).
- Identifiers, protocol names (methods, events, JSON fields), config keys and
  commit messages remain in English.
