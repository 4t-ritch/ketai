# ketai

## Language rules

- Code comments and documentation (`docs/`, README, guides) must be written in Spanish using ASCII-only characters.
- Do not use accents, tildes, or special characters: write `cancion`, `reproduccion`, `ano`, `senal` (not `canción`, `reproducción`, `año`, `señal`).
- Do not use inverted punctuation (`¿`, `¡`).
- Identifiers, protocol names (methods, events, JSON fields), and commit messages remain in English.
